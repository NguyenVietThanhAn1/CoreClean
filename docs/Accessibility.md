# Accessibility

CoreClean targets WCAG 2.1 AA compliance on Android. This document lists TalkBack pass criteria and contrast requirements.

## TalkBack Pass Criteria

### Icon rules
- **Decorative icons** (purely visual, adjacent text explains context): `contentDescription = null`
- **Informative icons** (standalone meaning): `contentDescription = stringResource(R.string.cd_*)`
- **Clickable icons via `IconButton`**: the `Icon` inside must have `contentDescription`

### Canvas composables
All `Canvas` composables that represent data must include `Modifier.semantics { contentDescription = "..." }`:
- `BatteryCircle` → `cd_battery_circle` (reports level %)
- `StorageDonutChart` → `cd_storage_donut` (reports used / total)

### Touch targets
- All interactive components must be ≥ 48 dp × 48 dp (Material 3 minimum)
- `IconButton` defaults to 48 dp — do not shrink with custom Modifier.size on the button itself

### Content description strings
All `cd_*` strings are defined in `app/src/main/res/values/strings.xml` and mirrored to `values-en/strings.xml`.

| String key               | Used in                    |
|--------------------------|----------------------------|
| `cd_settings`            | HomeScreen settings icon   |
| `cd_back`                | All back navigation icons  |
| `cd_battery_circle`      | BatteryScreen canvas       |
| `cd_battery_prediction`  | BatteryScreen prediction card |
| `cd_storage_donut`       | StorageScreen canvas       |
| `cd_permission_granted`  | PrivacyDashboardScreen     |
| `cd_permission_denied`   | PrivacyDashboardScreen     |

## Contrast Requirements (Material 3)

Material 3 color roles automatically satisfy 4.5:1 (text on container) when using the system-generated color scheme. Custom colors must be verified with [Material Color Utilities](https://github.com/material-foundation/material-color-utilities).

- `batteryColor()` greens/oranges/reds are used on `Canvas`, not on text → no contrast requirement
- `primaryContainer` / `onPrimaryContainer` used in `FeatureCard` — auto-generated by Material You → compliant

## Screen Reader Flow (TalkBack)

Verified flows (Sprint 6):
1. **Home → Settings**: HomeScreen → tap Settings button (cd: "Cài đặt") → SettingsScreen
2. **Battery screen**: Level reported via BatteryCircle semantics; prediction card announces estimate
3. **Privacy Dashboard**: Permission icons announce granted/denied status with permission name
4. **Storage screen**: Donut chart announces used/total bytes

## CI Check

`./gradlew :app:lintDebug` enforces `ContentDescription` lint rules. The `scripts/a11y-check.sh` script runs accessibility checks via `apkanalyzer`.
